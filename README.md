# FocusUp 📚⏱️

FocusUp es una aplicación móvil diseñada para mejorar la productividad y organización personal mediante herramientas de planificación, gestión de tareas y técnica Pomodoro.

El objetivo principal de la aplicación es ayudar a los usuarios a organizar sus actividades diarias, mantener la concentración y realizar seguimiento de sus hábitos de estudio o trabajo.

## ✨ Características principales

- ✅ Gestión de tareas pendientes.
- ⏱️ Temporizador Pomodoro para sesiones de concentración.
- 📊 Estadísticas de productividad.
- 👤 Perfil de usuario.
- 📅 Organización y seguimiento de actividades.
- 🎨 Interfaz diseñada para ofrecer una experiencia sencilla e intuitiva.

## 🛠️ Tecnologías utilizadas

- **Kotlin** - Lenguaje principal de desarrollo.
- **Android Studio** - Entorno de desarrollo.
- **XML** - Diseño de interfaces.
- **Material Design 3** - Componentes visuales.
- **Gradle** - Gestión del proyecto.
- **Git/GitHub** - Control de versiones.

## 🚀 Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/DanielCastiblanco-Lopez/FocusUp-Android.git ```


2. Abrir el proyecto en Android Studio.
3. Esperar la sincronización de Gradle.
4. Ejecutar la aplicación en un dispositivo Android o emulador.
